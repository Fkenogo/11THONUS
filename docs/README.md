## 6. Rules for Document Changes

1. **No source document may be edited without appending an entry to the [changes log](00-governance/documentation-changes-log.md).**
2. Classify every edit: Editorial / Normalization / Clarification / Decision Required / Material Change (TRD consolidation audit §25). Decision Required and Material items stop and go to the founder.
3. Never resolve an open decision inside a document edit.
4. Never edit archived documents' historical body content.
5. Never delete audit evidence or backups.
6. Requirement IDs may only change through the planned ID-normalization phase with a published mapping table.
